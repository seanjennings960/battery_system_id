# Codex Development Standards

## Devcontainer development
- This project is developed in a dual Codex/VSCode environment
- They use the Python/Hatch-based devcontainer in `.devcontainer` to ensure reproducibility
- Run all commands via the `devcontainer` CLI, unless the task specifically requires administration-level access outside of container

## Code Review Workflow
- When code is requested, create a Github PR so it can be reviewed manually.
- Use the Github plugin/skill
- Keep PRs concise and reviewable: 250-500 lines max, wherever possible.

## Coding Style
- This is a Python/Hatch-based project
- Follow the Zen of Python
- Keep code minimal and mathematical as much as possible
